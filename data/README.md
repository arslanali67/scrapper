# Area data

`us_states.csv`, `us_cities.csv` and `us_zips.csv` are built by `build_us_data.py` from the
[GeoNames](https://www.geonames.org/) exports `cities1000.zip` and `US.zip`, licensed under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Data © GeoNames contributors; trimmed to US
populated places (city, state, population, coordinates) and US ZIP codes. Built 2026-11-04.

Used by the Google scraper (M8: state -> cities -> ZIP codes) and the LinkedIn X-ray fallback (M9).
